PFT PHRASEOLOGY REFERENCE — v1.0
Reviewed 2026-10-08

Purpose: give another language model a complete, structured starting point for adding metric-dependent PFT phrase selection to an existing repository.
All phrases below are original examples. They are not official society-mandated wording. Core thresholds and physiologic definitions are tied to the listed primary standards; etiologic comments are clinical inferences requiring review.
Scope: adult reports in English. This covers clinically distinct routine findings and common adjunct tests, rather than every possible sentence or pediatric/CPET reporting.
Read START_HERE.txt and PFT_Rules_and_Integration.txt before wiring the catalog to a UI. Evidence metadata belongs in the application reference/help layer, not in the copy-ready clinical report.
Catalog: 279 finding options and 901 written phrase variants.

TEST QUALITY AND LIMITATIONS
Use observed or laboratory-supplied quality findings. Grade FEV1 and FVC separately; report quality for each test component. Quality states must never be inferred from the numerical result alone.

quality.acceptable — Acceptable and repeatable
Eligibility: documented_observation; observations.quality.acceptable = True
Concise: Acceptable, repeatable spirometry.
Standard: Spirometry meets acceptability and repeatability criteria.
Expanded: The spirometry maneuvers meet laboratory acceptability and repeatability criteria; reported values are suitable for interpretation.
Rule note: Use only when the corresponding limitation or quality status is documented.
Evidence anchors: S19, L23, D17, M19

quality.limited_repeatability — Repeatability limitation
Eligibility: documented_observation; observations.quality.limited_repeatability = True
Concise: Spirometry is not repeatable.
Standard: Spirometry repeatability criteria were not met.
Expanded: Variation between efforts limits confidence in the reported spirometric values and in classification near the reference limits.
Rule note: Use only when the corresponding limitation or quality status is documented.
Evidence anchors: S19, L23, D17, M19

quality.usable — Usable, incompletely acceptable
Eligibility: documented_observation; observations.quality.usable = True
Concise: Spirometry is usable with limitations.
Standard: Usable spirometry was obtained, although full acceptability criteria were not met.
Expanded: The available maneuvers support a cautious interpretation; technical limitations should be considered when assessing the size of an abnormality.
Rule note: Use only when the corresponding limitation or quality status is documented.
Evidence anchors: S19, L23, D17, M19

INDIVIDUAL SPIROMETRY METRICS
A metric statement describes the measurement. Physiologic pattern statements use combinations of valid metrics. A low FEV1 is not synonymous with obstruction, and a high FEV1/FVC is not a diagnosis.

metric.fev1.normal — FEV1 within reference limits
Eligibility: automatic; spirometry.fev1_state = normal
Concise: FEV1 is within reference limits.
Standard: FEV1 is within the expected reference range.
Expanded: FEV1 is within reference limits for the selected equation; its relationship to other measurements determines the physiologic pattern.
Numeric: FEV1 is {fev1_L} L ({fev1_pct_pred}% predicted; z-score {fev1_z}).
Evidence anchors: I22

metric.fev1.low — FEV1 below LLN
Eligibility: automatic; spirometry.fev1_state = low
Concise: FEV1 is reduced.
Standard: FEV1 is below the lower limit of normal.
Expanded: FEV1 is reduced relative to the selected reference equation; this finding alone does not establish its cause.
Numeric: FEV1 is {fev1_L} L ({fev1_pct_pred}% predicted; z-score {fev1_z}).
Evidence anchors: I22

SPIROMETRIC AND VENTILATORY PATTERNS
Use reliable TLC to confirm restriction and mixed impairment. Preserve component labels when quality is limited. PRISm is a defined phenotype whose thresholds must be declared.

pattern.normal — Normal spirometry
Eligibility: automatic; patterns.normal = True
Concise: Spirometry is normal.
Standard: FEV1, FVC, and FEV1/FVC are within reference limits.
Expanded: Spirometry is within reference limits; lung volumes, gas transfer, and clinical context provide additional information.
Evidence anchors: I22

pattern.obstruction — Obstructive impairment
Eligibility: automatic; patterns.obstruction = True
Concise: Obstructive ventilatory impairment.
Standard: Spirometry demonstrates an obstructive ventilatory impairment.
Expanded: FEV1/FVC is below the LLN, supporting an obstructive ventilatory impairment.
Evidence anchors: I22

pattern.obstruction_preserved_fev1 — Obstruction with preserved FEV1
Eligibility: automatic; patterns.obstruction_preserved_fev1 = True
Concise: Obstruction with preserved FEV1.
Standard: FEV1/FVC is reduced, with FEV1 remaining within reference limits.
Expanded: An obstructive ventilatory impairment is present despite a preserved FEV1; the ratio identifies the pattern, while FEV1 describes the magnitude of impairment.
Evidence anchors: I22

pattern.low_fvc_unconfirmed — Low FVC, TLC unavailable
Eligibility: automatic; patterns.low_fvc_unconfirmed = True
Concise: Reduced FVC; restriction is unconfirmed.
Standard: FVC is reduced with a preserved ratio; lung volumes are required to assess for restriction.
Expanded: The low FVC with preserved FEV1/FVC suggests a possible restrictive pattern, but TLC is needed to distinguish restriction from other causes of reduced vital capacity.
Evidence anchors: I22

pattern.nonspecific — Nonspecific pattern
Eligibility: automatic; patterns.nonspecific = True
Concise: Nonspecific ventilatory pattern.
Standard: FEV1 and/or FVC are reduced with a preserved FEV1/FVC and normal TLC.
Expanded: Reduced spirometric volumes with a preserved ratio and TLC within reference limits constitute a nonspecific pattern; the cause requires clinical correlation.
Evidence anchors: I22

pattern.restriction — Confirmed restriction
Eligibility: automatic; patterns.restriction = True
Concise: Restrictive ventilatory impairment.
Standard: TLC is below the LLN, confirming a restrictive ventilatory impairment.
Expanded: A reduced TLC confirms restriction; spirometry and gas-transfer findings help characterize the associated physiology.
Evidence anchors: I22

pattern.simple_restriction — Simple restrictive pattern
Eligibility: automatic; patterns.simple_restriction = True
Concise: Simple restrictive pattern.
Standard: TLC is reduced without disproportionate elevation of residual-volume fractions.
Expanded: The lung-volume distribution is consistent with a simple restrictive pattern; this describes physiology and does not determine the underlying diagnosis.
Evidence anchors: I22

pattern.complex_restriction — Complex restrictive pattern
Eligibility: automatic; patterns.complex_restriction = True
Concise: Complex restrictive pattern.
Standard: Restriction is present with an increased residual-volume fraction and a preserved FEV1/FVC.
Expanded: The reduced TLC with disproportionately retained residual volume and a preserved ratio supports a complex restrictive pattern; reduced thoracic expansion and airway closure are possible contributors.
Evidence anchors: I22

pattern.mixed — Mixed impairment
Eligibility: automatic; patterns.mixed = True
Concise: Mixed obstructive and restrictive impairment.
Standard: FEV1/FVC and TLC are below their LLNs, indicating mixed impairment.
Expanded: Both airflow obstruction and restriction are present, supported by a reduced FEV1/FVC and reduced TLC.
Evidence anchors: I22
